# Published figure (not included)

`real_saed_extract.py`, `sim_vs_real.py` and `moire_16_24.py` analyse the electron diffraction figure from:

*Raman spectra of twisted CVD bilayer graphene*, Carbon 123, 302 (2017).

The figure is not included in this repository for copyright reasons. To rerun these scripts, save a screenshot of the diffraction figure here as `carbon2017_fig_saed.png`. The crop boxes in `real_saed_extract.py` (`PANELS`) were set for one particular screenshot, so you may need to adjust them for yours.
